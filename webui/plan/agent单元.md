# 初期agent单元
| 能力 | 首期应该做到 | 暂时不必做 |
| --- | --- | --- |
| 系统提示词 | 使用该 Agent 实际生效的 Prompt，并记录配置 | 复杂 Prompt 管理平台 |
| 上下文 | 记录本轮实际发送的消息、上游交接内容及截断结果 | 通用长上下文治理系统 |
| 记忆 | 明确本次运行内的 Agent 私有状态与共享状态边界 | 向量库、跨会话长期记忆 |
| Skills | 已配置技能有明确执行入口、输入输出和错误 | 完整技能安装、发现、分发体系 |
| 工具 | 根据绑定调用，记录参数、返回与失败 | 全功能插件市场 |
| 执行循环 | 模型 → 工具 → 模型，明确结束及上限 | 通用自主 Agent 操作系统 |
| 记录接口 | 在真实执行边界记录事件 | 完整观测平台 |
