--------------------------------------------------
LAYER 1: SUB-GOAL COMPLETION
--------------------------------------------------

SUBGOAL_COMPLETE when:
- Executor returned non-empty, relevant data for {Sub_Goal} in THIS step's result
- No hard failure (timeout, error, permission denied)
- For acquisition: result contains structured fields (URL, arXiv ID, zip, number, extracted text)
- For cross-reference tasks: TWO axis label pairs (e.g. Standardization vs Localization AND Utilitarianism vs Egalitarianism) are sufficient — a third axis is NOT required
- For multiple-choice questions, judge the requested medical/factual evidence only.
  The external source does NOT need to mention "Option A/B/C/D" or an option letter.

SUBGOAL_INCOMPLETE when:
- Empty/error/irrelevant result from executor
- Executor returns ABSENCE (not found / no details) with no structured fields
- Wrong tool class (e.g. Base_Generator for extract/retrieve)

CRITICAL: Do NOT mark SUBGOAL_COMPLETE based only on prior Obtained Information when the Latest Executor Result is ABSENCE or EMPTY.

--------------------------------------------------
EVIDENCE CLASSIFICATION
--------------------------------------------------

Evidence_Type — EXACTLY ONE:
- DIRECT: this step's result contains what the sub-goal asks for
- ABSENCE: this step explicitly states missing/not found/does not contain
- ERROR: tool failure/exception
- EMPTY: no usable content

Tool_Appropriate — false when the tool cannot satisfy this subgoal type.

Slot_Updates — for each required slot, report:
- slot name (final_term, axis_labels, zip_codes, computed_count, etc.)
- value ONLY if quoted or paraphrased from Latest Executor Result or explicitly new in this step
- filled=true ONLY when value is present in THIS step's evidence with citable text
- Do NOT set filled=true from Obtained Information alone if executor returned ABSENCE/EMPTY
- For multiple-choice final_answer, if THIS step's evidence uniquely supports one
  option's text, return that option text or its question-local label. The label is
  formatting metadata from the Question and need not appear in the external source.
- Never mark a retrieval sub-goal incomplete merely because the source omits an
  option letter; do not recommend another search for a page explicitly stating Option X.

Cross-reference tasks: when two axis pairs and a societal descriptor term (e.g. egalitarian) both appear in cumulative evidence from THIS or prior steps WITH structured citations, you may set final_term filled=true with the matching word.

--------------------------------------------------
LAYER 2: TASK STATUS (REPORT ONLY)
--------------------------------------------------

Do NOT return STOP. Always set Conclusion=CONTINUE or null.

--------------------------------------------------
OUTPUT FORMAT (STRICT JSON ONLY)

{{

NOTES:
- Subgoal_Conclusion reflects ONLY whether THIS executor result completed the sub-goal.
- slot_updates.filled=true requires citable support in Latest Executor Result (or explicit structured fields therein).
- ABSENCE from executor → SUBGOAL_INCOMPLETE unless slot_updates show new fills from executor text.
