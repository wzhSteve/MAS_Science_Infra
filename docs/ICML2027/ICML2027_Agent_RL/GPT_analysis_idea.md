我仔细审阅了你上传的《RAE: Recovery-Aware Exploration with Counterfactual Policy Elimination——算法设计与实现方案》。以下以 ICML 2027 严格审稿人的标准进行评估，重点检查四个问题：

二、首先明确：RAE 真正值得发表的贡献是什么？

我认为，在进一步修改公式之前，必须先确定论文究竟要解决什么问题。

你的文档已经指出了四个缺口：

* 不确定性不等于值得探索；
* 内部信念变化不等于环境中的真实表现；
* 失败不应该只被压缩成标量惩罚；
* Agent 最有学习价值的片段可能是局部恢复过程，而不是完整轨迹。

这些动机是合理的。 RAE_算法设计与实现-ICML2027.md

但它们并不自动构成四项独立贡献。

从审稿人的角度，我会把它们统一到一个更明确的问题上。

2.1 传统 Agent RL 优化什么？

设任务的初始状态为 s_0，Agent 执行策略 \pi_\theta，最终得到成功指标：

Y(\tau)\in\{0,1\}.

常见的结果导向优化可以写成：

\max_\theta
J(\theta)
=
\mathbb E_{\tau\sim\pi_\theta}
[Y(\tau)].

在这种设定下，失败轨迹通常通过负优势、结果奖励或者其他形式的梯度信号影响策略。

问题在于：

一条失败轨迹只能说明整条执行过程没有成功，并不能直接确定应该削弱哪个动作、保留哪个动作，以及下一次应该尝试哪个替代动作。

例如：

a_1\rightarrow a_2\rightarrow a_3\rightarrow \text{Failure}.

失败可能源于：

* a_1 本身错误；
* a_1 合理，但 a_2 不适配当前状态；
* a_1,a_2 都合理，只是 a_3 错误；
* 所有动作都合理，但后续策略无法完成任务；
* 环境随机性导致最终失败。

仅根据终局结果，通常无法区分这些情形。

这正是 RAE 可以切入的问题。

2.2 我建议重新定义核心研究问题

我建议把论文的核心问题写成：

在有限交互预算下，如何利用失败轨迹选择值得评估的决策状态，通过可比较的反事实执行获取动作级证据，并将这些证据转化为能够提高后续任务成功率的策略更新？

这比“利用失败进行探索”更加准确。

它包含三个必须同时解决的问题：

1. Decision selection： 哪个决策状态值得付出额外预算？
2. Counterfactual evaluation： 哪些动作在相同条件下更值得保留？
3. Evidence-guided learning： 如何将评估结果转化为策略更新？

这三个问题之间存在依赖关系。

如果选错状态，反事实预算就浪费了。

如果探针没有真正评估指定动作，证据就不可靠。

如果证据无法正确映射到策略更新，前两个模块即使有效，也未必提高任务成功率。

因此，我建议论文只保留一个核心贡献：

Budgeted Counterfactual Recovery for Agentic RL。

RAE 可以继续作为方法名称，但理论和实验都应该围绕这个核心展开。

三、最关键的算法问题：当前探针是否真的在评估候选动作？

这是我认为整份设计稿中最需要优先解决的问题。

它不是理论表达上的小瑕疵，而是可能影响整个算法成立与否的问题。

3.1 文档中的定义

你的文档定义了动作 a_i 在上下文 h 下的协议条件化成功率：

p_i
=
P(Y=1\mid h,a_i,\mu).

其中，\mu 包含动作执行方式、后续策略、执行预算、终止条件和随机性控制。 RAE_算法设计与实现-ICML2027.md

这个定义本身是合理的。

如果要判断动作 a_i 是否值得保留，就需要估计：

p_i=P(Y=1\mid h,\operatorname{do}(a_i),\mu),

这里的 \operatorname{do}(a_i) 表示在指定上下文中实际执行候选动作 a_i，而不是再次让策略自由采样动作。

两者存在本质区别。

3.2 当前实现描述可能没有执行指定动作

在 §7.1 中，文档将探针请求描述为：

prompt + response[:t_s^{(i)}]

即以候选动作 span 的起点为新 prompt，然后进行第二程生成。

但是，如果 t_s^{(i)} 是候选动作的起点，那么这个前缀并没有包含候选动作本身。

后续生成过程实际上可能重新采样动作。

此时，探针观测到的不是：

Y\mid h,a_i,

而是：

Y\mid h,\pi_{\mathrm{ref}},\mu.

在这种情况下，探针成功率不能用于区分不同候选动作。

例如，假设两个候选动作分别是：

* a_1：调用搜索工具；
* a_2：直接生成答案。

如果两组探针都从动作生成之前的同一个上下文重新采样，那么两组结果主要反映的是策略重新采样后的行为，而不一定反映 a_1 和 a_2 各自的效果。

这会破坏 RAE 最核心的证据获取环节。

这是一个必须在实现和论文中彻底消除的歧义。

3.3 正确的探针协议应该是什么？

我建议明确区分三个阶段。

阶段 A：候选动作生成

从当前上下文 h 采样候选动作：

a_i\sim \pi_{\mathrm{ref}}(\cdot\mid h).

将语义相同的动作去重，得到：

\mathcal A_h=\{a_1,\ldots,a_n\}.

阶段 B：强制执行候选动作

对于每个候选动作，探针必须从相同的决策上下文开始，并强制执行该动作：

\tau_{i,k}
\sim
P_\mu
\left(
\tau
\mid
h,\operatorname{do}(a_i)
\right).

然后让后续策略继续执行，直到成功、失败或达到规定的预算上限。

得到：

Y_{i,k}
=
\mathbb 1[\tau_{i,k}\text{ 成功}].

这里的关键是：

候选动作必须被实际执行，而不是只作为一个生成提示或动作标签。

如果动作是一个工具调用，就应该执行该工具调用，并把真实环境返回结果回填给后续 Agent。

如果动作是一个自然语言决策块，则需要明确如何保证该动作被保留，以及后续环境如何解释它。

阶段 C：估计动作的协议条件化表现

在固定执行协议 \mu 下：

p_i^\mu(h)
=
P_\mu
\left(
Y=1
\mid
h,\operatorname{do}(a_i)
\right).

这一量才是后续贝叶斯估计与动作裁决的目标。

需要注意，这仍然是一个协议条件化的动作效果，不是跨所有后续策略、环境和执行预算都成立的普适因果效应。

你的原稿已经注意到了这一归因边界，这一点应该保留。

3.4 第二个相关问题：随机种子与反事实可比性

你的文档强调相同执行协议和随机性控制。

这里还需要更严格地区分两种情况：

* 对确定性环境，相同初始状态与动作执行协议通常足以建立较强的可比性。
* 对随机环境，两个候选动作即使使用相同随机种子，也不一定经历相同的随机扰动，因为不同动作可能触发不同的环境转移路径。

因此，论文应该明确估计的是：

p_i^\mu(h)
=
\mathbb E_{\xi}
\left[
Y\mid h,\operatorname{do}(a_i),\xi,\mu
\right],

其中 \xi 表示环境随机性。

如果环境允许 common random numbers 等方差降低技术，可以作为额外优化，但不应该将其视为反事实识别成立的必要条件。

我的审稿判断

这一部分是 P0 阶段最重要的正确性检查。

在完成之前，不建议投入大量时间研究更复杂的后验裁决器、可靠性权重或者蒸馏损失。

因为如果探针估计的对象不正确，后续数学再严谨也无法修复这一问题。

四、第二个核心问题：p_{\mathrm{ref}} 的定义还不够严谨

你的设计采用同上下文初始 rollout 组的成功率作为优先参照：

p_{\mathrm{ref}}
\approx
\frac{1}{N}\sum_{j=1}^{N}Y_j.

随后使用：

e_i
=
w_i(\hat p_i-\hat p_{\mathrm{ref}})

构造候选动作的证据分数。

直觉上，这相当于问：

执行候选动作后，成功率是否比当前策略的基线更高？

问题在于，候选动作探针与初始 rollout 必须具有可比的结果生成协议。

4.1 初始策略成功率与候选动作成功率可能不是同一个统计量

设初始策略成功率为：

p_0
=
P(Y=1\mid h,\pi_{\mathrm{ref}},\mu_0).

候选动作的成功率为：

p_i
=
P(Y=1\mid h,\operatorname{do}(a_i),\mu_i).

如果两者的执行预算、后续策略、截断规则或终止条件不同，那么：

p_i-p_0

就不再是一个干净的动作比较量。

举个例子：

* 初始 rollout 可以执行 20 步；
* 候选动作探针只允许执行 5 步；
* 两者都用最终是否成功作为二值标签。

这时，候选动作的成功率较低，可能是因为它确实较差，也可能是因为探针预算更短。

同样，如果探针使用较弱的后续策略，而初始 rollout 使用较强的策略，也会产生系统性偏差。

4.2 我的建议：明确两种不同的估计目标

你需要先决定论文究竟要回答哪个问题。

方案 A：动作的绝对成功潜力

定义：

p_i^\mu(h)
=
P_\mu
\left(
Y=1\mid h,\operatorname{do}(a_i)
\right).

此时，p_i 是候选动作在固定后续执行协议下的成功率。

如果目标是选择更有潜力的动作，可以直接比较候选动作之间的差异：

\Delta_{ij}
=
p_i^\mu(h)-p_j^\mu(h).

这一方案更适合动作排序和有限预算的最佳动作识别。

方案 B：候选动作相对于当前策略的改进幅度

定义：

\Delta_i
=
p_i^\mu(h)-p_0^\mu(h).

此时，p_0^\mu(h) 必须是与候选探针使用相同后续协议的参照成功率。

这一方案更适合判断：

是否值得将当前策略的概率质量转移给候选动作？

我更倾向于方案 B 作为 RAE 的最终学习目标，但方案 A 作为理论和实验分析的基础。

原因是你的最终目的不是找到某个动作的绝对成功率，而是纠正当前策略对不同动作的相对偏好。

同时，我建议使用成对比较或共同参照的后验分析，而不是将一个未经校准的初始 rollout 均值直接当作精确的 p_{\mathrm{ref}}。

五、第三个核心问题：当前理论定理不够支撑 ICML

这是我对当前稿件最大的理论方面的担忧。

你的 §8.2 给出了定理 1’：

q^*
=
\arg\min_q
\left[
D_{\mathrm{KL}}(q\Vert\bar\pi_{\mathrm{ref}})
-
\beta\sum_i q_i e_i
\right],

其闭式解为：

q^*(a_i)
=
\frac{
\bar\pi_i\exp(\beta e_i)
}{
\sum_j\bar\pi_j\exp(\beta e_j)
}.

你也给出了相应的拉格朗日乘子证明。 RAE_算法设计与实现-ICML2027.md

这一定理是正确的。

但我认为，它只能证明目标分布构造具有合理的优化解释，不能证明 RAE 的核心研究主张。

5.1 为什么定理 1’ 不够？

因为它没有回答以下问题：

1. 反事实探针得到的证据是否足够准确？
2. 在固定预算下，为什么自适应分配比均匀采样更有效？
3. 证据误差会怎样影响目标分布？
4. 目标分布重构为什么会提高任务成功率？
5. RAE 相比普通失败负优势，究竟能减少多少决策错误？

定理 1’ 的逻辑是：

给定一个证据向量 e，就可以构造一个满足特定 KL 正则化目标的分布 q^*。

但它没有证明这个 e 是正确的。

你在文档中已经承认，定理只保证给定 e 后的目标最优，证据估计误差仍然会直接传导为目标错误。这个边界判断是正确的。

问题在于：既然论文的主要创新是获得更好的证据，那么最重要的理论应该研究证据获取和证据误差，而不应该停留在证据给定后的标准优化问题。

5.2 我建议重新安排理论贡献的层级

保留定理 1’，但将其从主要理论贡献降级为：

Proposition 1: Evidence-Regularized Target Construction。

真正的理论贡献应该至少增加一个有限预算的决策定理，并争取增加一个目标误差传播定理。

我建议采用下面的组合。

理论结果	研究问题	对 ICML 贡献的意义
Proposition 1	证据如何转化为目标分布？	提供方法的优化基础
Theorem 1	有限探针预算下，动作裁决错误概率如何随样本数变化？	提供统计保证
Theorem 2	自适应分配相较均匀分配何时能够减少决策错误？	解释核心算法机制
Theorem 3（可选）	目标分布误差如何传导到策略成功率？	将证据质量与最终任务收益联系起来

其中，Theorem 2 是最值得优先投入的理论结果。

但是，不能先假定自适应分配一定优于均匀分配，再去寻找一个支持该结论的证明。

你需要明确假设、预算定义、比较基准以及保证的适用范围。

六、我最推荐的理论方向：有限预算的贝叶斯动作识别

你的方法中，真正具有研究价值的并不是 Beta-Binomial 本身，而是：

如何将有限的环境交互预算分配给不同候选动作，从而尽可能减少最终的策略决策错误。

这可以构成一个相对完整的理论问题。

6.1 先定义有限动作识别问题

给定上下文 h 和候选动作集合：

\mathcal A_h=\{a_1,\ldots,a_n\}.

对每个候选动作，定义协议条件化成功率：

p_i=P_\mu(Y=1\mid h,\operatorname{do}(a_i)).

为了简化第一版理论，假设：

Y_{i,k}\mid p_i
\sim
\operatorname{Bernoulli}(p_i),

并且给定 p_i 后，同一动作的探针结局条件独立。

这个假设需要在论文中明确说明；如果实际环境存在明显的非平稳性，就需要进一步扩展。

每次评估动作 a_i，都需要消耗一定的预算。

设总探针预算为：

\sum_{i=1}^{n}K_i\le B.

问题是如何选择 K_i，使最终决策质量最大。

这里有两种可能的理论目标。

目标 A：最佳动作识别

定义：

i^*=\arg\max_i p_i.

希望在预算 B 内尽可能高概率地识别 i^*。

这一问题可以使用有限样本的最佳臂识别理论作为基础。

但它不完全等价于 RAE 的目标，因为 RAE 并不一定要选出一个唯一最优动作。

目标 B：策略分布识别

RAE 希望保留多个有价值的动作，并重构：

q^*(a_i)
\propto
\bar\pi_i\exp(\beta e_i).

因此，更贴近 RAE 的目标是：

\min_{\{K_i\}}
\mathbb E
\left[
D_{\mathrm{KL}}
\left(
q^*(\cdot\mid h)
\Vert
\hat q_B(\cdot\mid h)
\right)
\right],

其中 \hat q_B 是根据有限预算内获得的探针数据构造的目标分布。

这里有一个重要的技术细节：

真实的 q^* 依赖未知的 p_i，因此这个目标主要用于理论分析，不是训练时可直接计算的量。

同时，KL 的方向很重要。如果你的重点是避免对真正有价值的动作赋予过低概率，反向 KL 或其他决策损失可能更合适。因此，建议在理论设计时同时考虑目标误差和最终决策风险，而不是预先固定某个距离。

6.2 一个可争取的定理方向

我建议尝试证明以下类型的结果。

Theorem A：有限预算下的目标分布误差界

在以下条件下：

1. 候选动作集合有限；
2. 各动作的探针结果满足条件独立的 Bernoulli 模型；
3. 执行协议在评估过程中固定；
4. 目标分布使用已定义的证据映射构造；
5. 后验估计满足相应的误差控制条件；

可以研究：

D\left(q^*,\hat q_B\right)
\le
f\left(
B,\{\text{动作间隔}\},\beta,\{\text{先验参数}\}
\right)

以高概率成立，或者给出相应的期望风险界。

这里的 D 可以是适当选择的分布距离。

这个结果的价值在于，它可以回答：

* 预算增加时，目标分布误差如何变化？
* 动作成功率越接近，是否需要更多探针？
* \beta 增大后，目标分布是否更容易受到统计误差影响？
* 哪些情况下，更多的探针实际上无法显著改变策略目标？

不过，这只是建议研究的定理方向，不是已经证明的结论。

尤其是 q^* 依赖后验估计的非线性映射，不能直接将某个单动作的置信区间套入目标分布，就声称获得了严格的 KL 误差界。

需要仔细处理指数映射、归一化以及极端概率质量变化。

七、比目标分布闭式解更有价值的理论：何时应该继续探针？

我认为这才是 RAE 最有机会做出区别的部分。

你的当前方案使用：

w_i^{\mathrm{alloc}}
\propto
\tilde H^\pi(h)\cdot H_b(\hat p_i)

为候选动作分配追加探针预算。

但是，当前启发式存在一个更深层的问题：

它主要根据候选动作的不确定性分配预算，而没有直接衡量减少这种不确定性是否会改变最终的策略决策。

这是我建议重点研究的地方。

7.1 为什么高不确定性不等于高决策价值？

考虑两个候选动作。

情形 A：成功率差距很大

p_1=0.95,\qquad p_2=0.20.

如果当前证据已经足以区分二者，那么即使继续采样仍能减少统计方差，其实际决策价值可能很小。

情形 B：两个候选动作非常接近

p_1=0.52,\qquad p_2=0.48.

当前策略可能对二者有相当的概率质量。

继续探针可能改变两者的相对权重，但也可能在有限预算下无法获得足够证据。

因此，不能仅仅根据 Bernoulli 熵判断哪个动作更值得继续采样。

还需要考虑：

* 当前候选动作的后验分布；
* 候选动作之间的成功率差异；
* 当前参考策略对各动作的概率质量；
* 目标温度 \beta；
* 追加探针是否可能改变最终的目标分布或动作排序。

7.2 我建议将预算分配从启发式升级为决策风险最小化

首先，定义基于当前证据的目标分布：

q_t=\mathcal T(\mathcal D_t),

其中 \mathcal D_t 表示截至时刻 t 的全部探针数据，\mathcal T 是 RAE 的目标构造算子。

然后，定义一个决策损失：

\mathcal R(q,p),

它衡量当前目标分布 q 在真实动作成功率 p=(p_1,\ldots,p_n) 下的决策风险。

接着定义当前的后验决策风险：

\mathfrak R(\mathcal D_t)
=
\mathbb E
\left[
\mathcal R(q_t,p)
\mid \mathcal D_t
\right].

对于候选动作 a_i，考虑再获得一次探针结果 Y_i 后，预期风险降低量：

\operatorname{VOI}_i
=
\mathfrak R(\mathcal D_t)
-
\mathbb E_{Y_i\mid\mathcal D_t}
\left[
\mathfrak R(\mathcal D_t\cup\{Y_i\})
\right].

如果每个动作的探针成本相同，可以优先评估 VOI 较高的动作。

如果成本不同，则可以进一步研究单位成本的预期风险降低：

\frac{\operatorname{VOI}_i}{c_i}.

这里的 VOI 是基于决策风险定义的，而不是单纯基于信息增益。

这是我最建议你探索的理论路线。

它与当前方案的关键差别是：

当前方案	建议研究的方案
用熵和探针结果不确定性分配预算	用预期决策风险降低分配预算
不确定的动作优先采样	只有可能改变最终决策的动作才优先采样
启发式分数	有明确决策目标的预算分配准则
需要实验验证其有效性	可以进一步研究近似最优性或有限预算风险界

但也要注意：定义了 VOI 并不自动证明它在计算上可行，更不自动证明贪心分配是最优的。

如果你要把它作为主要理论贡献，就需要进一步分析：

1. 风险函数是否具有有用的结构；
2. VOI 是否可以有效估计；
3. 贪心预算分配是否具有近似保证；
4. 在什么条件下，相比均匀分配可以获得严格改善。

这条路线比继续增加熵启发式的复杂程度更值得投入。

八、第四个问题：目标分布构造合理，但当前证据函数还没有足够的统计解释

你的软目标分布为：

q_{\mathrm{RAE}}(a_i\mid h)
=
\frac{
\bar\pi_i\exp(\beta e_i)
}{
\sum_j\bar\pi_j\exp(\beta e_j)

它的优点是保留了参考策略的相对结构，并允许证据对候选动作的概率质量进行调整。

这是一个合理的设计。

* 目标分布的优化形式是否合理？
* 证据分数是否真的能支持这种调整？

8.1 当前证据分数的主要问题

你的文档采用：

e_i
=
\begin{cases}
+w_i(\hat p_i-\hat p_{\mathrm{ref}}),
& \text{Validated},\\
-w_i(\hat p_{\mathrm{ref}}-\hat p_i),
& \text{Invalidated},\\
0,
& \text{Abstain}.
\end{cases}

这里有三个值得注意的问题。

问题一：裁决与证据幅度可能重复使用同一信息

Validated 和 Invalidated 本身已经是由后验概率阈值决定的。

随后，证据分数又使用后验均值差异和可靠性权重。

这种设计不一定错误，但需要解释：

为什么既需要三态裁决，又需要一个连续证据分数？

如果三态裁决只是用于日志和分析，而实际目标完全由连续后验差异决定，那么可以考虑去掉硬裁决，直接构造连续目标。

反之，如果三态裁决决定是否允许调整概率质量，那么连续证据分数就应该服务于这一决策机制。

两者应当具有清晰分工。

问题二：可靠性权重可能无法正确反映目标分布误差

你给出的：

w_i
=
\left(
1+
\frac{\operatorname{Var}[p_i\mid\mathcal D_i]}
{\operatorname{Var}_{\mathrm{floor}}}
\right)^{-1}

可以作为平滑启发式，但它没有直接刻画：

* 当前后验是否足以支持动作排序；
* 证据误差对 q_i 的影响；
* 错误地降低一个高价值动作的概率质量会产生多大代价。

因此，不建议将这一权重作为方法的主要理论创新。

问题三：p_i 的统计不确定性不等于动作决策的不确定性

两个动作的成功率估计可能都具有较大的后验方差，但它们的后验差值却可能足以支持稳定排序。

反过来，即使单个动作的后验方差不大，如果两个动作的成功率非常接近，排序仍可能不稳定。

所以，真正应该关注的可能是：

P(p_i>p_j\mid\mathcal D),

或者：

P(p_i>p_{\mathrm{ref}}\mid\mathcal D),

而不只是单个动作的后验方差。

这也与前面建议的决策风险驱动预算分配相一致。

8.2 我的建议：第一版使用最简单的证据映射

为了让论文的核心贡献更清晰，我建议第一版不要同时引入太多可靠性机制。

可以先定义：

e_i=\hat p_i-\hat p_0,

其中 \hat p_0 来自经过校准的共同参照。

然后：

q_i
=
\frac{
\bar\pi_i\exp(\beta e_i)
}{
\sum_j\bar\pi_j\exp(\beta e_j)
}.

之后再通过消融实验判断是否需要：

* 后验置信度加权；
* 三态裁决；
* Invalidated 概率下限；
* 硬约束下的硬消除。

这有一个明显好处：

先证明动作级反事实证据本身有价值，再证明复杂的证据可靠性机制有额外价值。

否则，如果完整 RAE 获得提升，审稿人很难判断究竟是反事实评估、贝叶斯后验、目标分布重构，还是额外的平滑与截断机制在起作用。

九、第五个关键问题：当前蒸馏损失与理论目标分布之间存在实现不一致

这一点必须明确修正。

你的文档定义了：

\mathcal L_{\mathrm{distill}}(h)
=
-\sum_i q_i\log\pi_\theta(a_i\mid h).

同时，你将动作概率定义为动作 span 上 token log-probability 的求和：

\log\pi_\theta(a_i\mid h)
=
\sum_{t\in\operatorname{span}_i}
\log\pi_\theta(y_t\mid y_{<t}).

这两者在数学上是一致的。

但 §9.3 又提出，行权重 q_i 只乘在动作 span 的起点，声称这样与整段序列对数似然语义等价。 RAE_算法设计与实现-ICML2027.md

这个说法不成立。

9.1 为什么只在 span 起点加权不等价？

设一个候选动作由三个 token 构成：

a_i=(y_1,y_2,y_3).

它的序列对数似然是：

\log\pi_\theta(a_i\mid h)
=
\log\pi_\theta(y_1\mid h)
+
\log\pi_\theta(y_2\mid h,y_1)
+
\log\pi_\theta(y_3\mid h,y_1,y_2).

因此：

\mathcal L_i
=
-q_i
\sum_{t=1}^{3}
\log\pi_\theta(y_t\mid y_{<t}).

相应的梯度是：

\nabla_\theta\mathcal L_i
=
-q_i
\sum_{t=1}^{3}
\nabla_\theta\log\pi_\theta(y_t\mid y_{<t}).

如果只在第一个 token 上乘 q_i，实际得到的却是：

\widetilde{\mathcal L}_i
=
-q_i\log\pi_\theta(y_1\mid h)
-
\sum_{t=2}^{3}
\log\pi_\theta(y_t\mid y_{<t}).

其梯度为：

\nabla_\theta\widetilde{\mathcal L}_i
=
-q_i\nabla_\theta\log\pi_\theta(y_1\mid h)
-
\sum_{t=2}^{3}
\nabla_\theta\log\pi_\theta(y_t\mid y_{<t}).

除非 q_i=1，或者存在特殊的梯度抵消条件，否则这两个梯度不相等。

所以：

将权重只乘在 span 起点，会改变原本定义的蒸馏目标。它不是对同一个序列级损失的等价实现。

9.2 正确的实现方式

建议直接使用序列级损失：

\boxed{
\mathcal L_{\mathrm{RAE}}
=
-\frac{1}{|\mathcal H|}
\sum_{h\in\mathcal H}
\sum_{i\in\mathcal A_h}
q_i
\sum_{t\in\operatorname{span}(a_i)}
\log\pi_\theta(y_t\mid y_{<t})
}

其中，\mathcal H 是参与蒸馏的决策上下文集合。

这一定义有几个优点：

1. 与理论中的 KL 蒸馏严格对应；
2. 明确 q_i 是动作级权重；
3. 不会将序列级权重错误地转化为 token 级权重；
4. 更容易分析候选动作长度和梯度规模的影响。

工程实现时，你可以选择以下两种归一化方式。

方式 A：按上下文归一化。

先对每个上下文计算完整的动作级蒸馏损失，再对上下文求平均。

这最接近理论定义。

方式 B：按有效 token 数归一化。

如果希望和 verl 的 token-mean 聚合方式一致，可以按有效 token 数归一化，但必须明确它对应的实际优化目标与序列级 KL 的关系。

特别是，当动作长度不同时，token-mean 与序列级平均并不自动等价。

我建议第一版以方式 A 作为主实验，方式 B 作为工程实现变体进行比较。

十、第六个问题：当前的 q_{\mathrm{RAE}} 是有限候选集上的分布，不是完整策略分布

这一点你在原稿中已经有所注意，但它对理论表述的影响还可以进一步加强。

你定义：

\bar\pi_i
=
\frac{
\pi_{\mathrm{ref}}(a_i\mid h)
}{
\sum_{a_j\in\mathcal A_h}
\pi_{\mathrm{ref}}(a_j\mid h)
}.

因此：

q_{\mathrm{RAE}}(a_i\mid h)

是有限候选集上的目标分布。

它并不是完整动作空间上的目标策略。

这意味着：

RAE 直接优化的是有限候选支持集上的相对动作概率，而不是完整策略的全局最优分布。

10.1 为什么这会影响理论？

假设当前策略的候选集合为：

\mathcal A_h=\{a_1,a_2,a_3\}.

但真正有价值的动作是 a_4，而它没有进入候选集合。

无论你如何重构：

q_{\mathrm{RAE}}(a_i\mid h),

都无法给 a_4 分配目标概率。

因此，最终学习效果受到两个因素的共同影响：

\text{学习误差}
=
\text{候选覆盖误差}
+
\text{候选内目标误差}.

这里的表达是概念性分解，严格数学定义还需要根据具体距离或风险函数确定。

这也说明，单纯证明：

q_{\mathrm{RAE}}
\propto
\bar\pi\exp(\beta e)

并不足以说明整个方法能够找到正确动作。

10.2 我建议将候选覆盖作为独立理论因素

可以考虑定义：

\mathcal A_h^{\mathrm{good}}
=
\{a:\ p(a\mid h)\ge p_{\mathrm{threshold}}\},

再研究：

P\left(
\mathcal A_h\cap\mathcal A_h^{\mathrm{good}}
\neq\varnothing
\right).

也就是说，首先考虑候选生成过程是否能够覆盖足够有价值的动作，再研究证据是否能够在候选集合中正确排序。

如果能够进一步建立候选覆盖率与最终决策风险之间的关系，论文的理论完整性会明显提高。

不过，这个方向可能需要对候选生成器作额外假设。你目前采用单一参考策略生成候选的设计，便于控制实验变量，但也限制了可获得的理论保证。

我的建议是：第一版先把候选覆盖率作为明确报告的机制指标，不必立即增加一个很强的候选生成理论。

11.1 H1：反事实证据是否真正提高恢复能力？

你的主对照包括：

* 普通失败负优势；
* APPO 式前缀回灌与 reward 缩放；
* RAE 目标分布蒸馏。

这组对照很重要。

但我建议至少补充两个控制。

控制一：相同探针数据，不同训练通道

让以下方法使用完全相同的候选动作、探针轨迹与结局：

1. 不使用探针结果；
2. 使用探针结果进行失败惩罚；
3. 使用探针结果进行前缀回灌；
4. 使用探针结果构造 q_{\mathrm{RAE}}；
5. 使用 oracle 动作价值构造目标分布，作为上界参考。

这样才能更直接地判断：

改进究竟来自获得了更多环境反馈，还是来自 RAE 的证据到目标分布通道？

其中，oracle 只能作为分析性上界，不能被当作一个具有相同信息条件的现实基线。

控制二：相同预算下比较

需要同时匹配：

* 生成 token 数；
* 环境调用数；
* 训练 token 数；
* 训练更新次数；
* 候选动作数量。

只匹配 rollout 数是不够的，因为 RAE 的探针可能具有不同的执行长度和环境调用成本。

11.2 H2：动作区分能力应该如何测量？

我建议不要只比较最终成功率。

应该为每个被选中的决策状态构造一个独立的评估集，并对候选动作进行更充分的评估，形成近似 oracle。

然后比较不同方法的动作价值判断。

建议报告：

* 动作价值排序相关性；
* 最佳候选识别率；
* 错误削弱高价值动作的比例；
* 错误保留低价值动作的比例；
* 目标分布与 oracle 目标分布的距离；
* 候选动作覆盖率。

其中，最重要的两个指标是：

False Elimination Rate： 将实际有价值的动作错误判为无效的比例。

Decision Regret： 最终目标分布或动作选择相对于 oracle 的决策损失。

这两个指标比单纯报告裁决准确率更符合 RAE 的研究目标。

11.3 H3：自适应预算分配是否真的优于均匀分配？

当前的 B6 包括均匀分配、熵与 Bernoulli 熵乘积，以及关闭 BS 预筛等对照。

这是一个好的开始。

但我建议增加一个直接与前面理论方向对应的基线：

Decision-Risk Adaptive Allocation。

即根据预期决策风险降低量分配预算。

这样实验不仅能够判断当前启发式是否有效，还能判断：

RAE 的主要收益究竟来自“自适应分配”本身，还是来自当前选择的特定熵启发式？

此外，需要增加预算从低到高的完整曲线，而不是只报告单一预算点。

对于每种预算：

B\in\{B_1,B_2,\ldots,B_m\},

分别报告：

* 最终任务成功率；
* 决策错误率；
* 目标分布误差；
* 单位预算带来的成功率增益；
* 探针与常规 rollout 的成本分解。

如果 RAE 只在较大预算下有效，那么它的主要贡献可能是额外采样，而不是更有效的失败恢复。

⸻

十二、第八个问题：论文新颖性必须从“模块组合”转向“新的决策原则”

这是 ICML 审稿中最容易影响评分的部分。

你的设计涉及：

* 熵引导分支；
* 策略内部的分支评分；
* 贝叶斯成功率估计；
* 三态裁决；
* 目标分布重构；
* KL 蒸馏；
* 自适应预算分配。

这些组件分别看都有合理性。

但审稿人可能会问：

为什么这些组件的组合是一个新的方法贡献，而不是已有技术在 Agent RL 中的一次工程集成？

尤其是以下两点：

1. 熵引导的分支采样已经有相关研究；
2. 根据评估结果重构目标分布并进行蒸馏，是一个相当通用的优化思路。

因此，论文不能只依靠“将这些组件组合起来”作为主要创新。

12.1 我建议将创新点压缩成两项

创新一：Recovery-Oriented Counterfactual Evidence

在失败轨迹上，选择具有纠错价值的决策状态，构造指定动作的反事实执行，并根据外部结果估计动作的协议条件化价值。

这里的创新重点是：

反事实执行不是为了增加训练样本，而是为了降低下一次策略决策的错误风险。

这需要通过同预算实验验证。

创新二：Decision-Aware Budgeted Evidence Acquisition

根据候选动作的后验不确定性和当前目标分布的决策敏感性，自适应分配探针预算。

这里的创新重点是：

预算分配不再只寻找高熵位置，而是寻找那些通过额外执行最有可能改变后续策略决策的位置。

这是我认为最值得发展成理论贡献的部分。

而目标分布重构和 KL 蒸馏，则作为将证据落地为策略更新的实现机制。

这种组织方式有一个明显优势：

它让论文的创新点与理论分析和实验指标一一对应，而不是依赖多个组件共同工作后的总体性能提升。

十三、我建议的理论框架：从启发式 RAE 转向可分析的 RAE

下面给出我建议的数学组织方式。

这是一个建议研究的框架，不是对现有算法的直接复述，也不是已经证明的理论结论。

13.1 问题定义

给定 Agent 决策上下文 h，候选动作集合：

\mathcal A_h=\{a_1,\ldots,a_n\}.

每个动作的成功率定义为：

p_i
=
P_\mu
\left(
Y=1
\mid
h,\operatorname{do}(a_i)
\right).

假设总探针预算为 B。

RAE 需要决定：

1. 哪些上下文值得评估；
2. 哪些候选动作值得追加探针；
3. 如何根据探针数据构造目标分布；
4. 如何通过参数更新逼近该目标分布。

13.2 将状态选择、动作评估和策略更新分离

第一层：状态选择

设：

z(h)\in\{0,1\}

表示是否对上下文 h 进行反事实评估。

状态选择策略可以使用熵、外部矛盾信号和最后承诺点等信息。

但在理论上，最终应该研究：

\text{评估状态 }h
\text{ 的预期价值是否超过其成本。}

这比单纯研究熵阈值更直接。

第二层：动作评估

对选中的上下文，构造候选动作并分配预算：

K(h)=\{K_1,\ldots,K_n\}.

满足：

\sum_i K_i\le B_h.

通过探针数据估计：

p_i\mid\mathcal D_i.

在第一版理论中，使用 Beta-Binomial 后验是合理的。

但需要明确，后验保证依赖于模型假设和数据生成过程。

第三层：目标策略重构

定义：

q^*(a_i\mid h)
=
\frac{
\bar\pi_i\exp(\beta e_i)
}{
\sum_j\bar\pi_j\exp(\beta e_j)
}.

这一步可以保留你当前的 KL 正则化解释。

不过，建议将 e_i 定义为一个明确的统计量，而不是同时混合过多的裁决与可靠性启发式。

第四层：参数更新

使用：

\mathcal L_{\mathrm{RAE}}
=
\mathbb E_h
\left[
D_{\mathrm{KL}}
\left(
q^*(\cdot\mid h)
\Vert
\pi_\theta(\cdot\mid h)
\right)
\right].

在实现中，通过动作级序列对数似然进行蒸馏。

这四层的优势在于，它们分别对应不同的可检验问题：

* 状态选择是否有效？
* 动作证据是否准确？
* 目标分布是否更接近合理决策？
* 参数更新是否能够逼近该目标？

如果你能进一步证明第二层的预算分配性质，并在第三层建立统计误差传播分析，这套框架才会从工程设计升级为更有说服力的算法论文。

十四、我建议优先推进的三个理论结果

考虑到 ICML 论文的篇幅和研究成本，我不建议同时追求很多复杂定理。

我建议先集中精力解决三个问题。

Theorem 1：有限预算下的动作决策错误界

研究在给定候选集合、执行协议和探针预算的条件下，RAE 对候选动作进行错误裁决的概率。

核心目标是得到：

P(\hat a\neq a^*)
\le
g(B,\Delta,\ldots),

其中 \Delta 表示相关动作之间的价值差异，其他参数根据具体模型定义。

但要注意：

如果目标是重构整个动作分布，而不是选择唯一最佳动作，就不能直接将最佳臂识别定理当作完整的理论结果。

此时应使用目标分布误差或决策风险。

Theorem 2：自适应预算分配的比较保证

研究：

\mathcal R(\mathcal A_{\mathrm{adaptive}})

与：

\mathcal R(\mathcal A_{\mathrm{uniform}})

之间的关系。

需要明确，不能对所有问题无条件声称自适应分配优于均匀分配。

一个合理的研究目标是：

* 在某些可分辨性或结构条件下，证明自适应策略能够改善有限预算下的决策风险；
* 对一般情况给出最优性差距或 regret 上界；
* 说明何时均匀分配已经足够好。

这比简单证明“高熵候选应该多采样”更有价值。

Theorem 3：目标分布误差向策略更新误差的传播

假设目标分布为 q^*，实际使用的估计目标为 \hat q，训练后的策略为 \pi_\theta。

可以研究：

D(q^*,\pi_\theta)

与以下误差之间的关系：

D(q^*,\hat q)

以及：

D(\hat q,\pi_\theta).

其意义在于区分：

* 证据估计不准；
* 目标分布构造不准；
* 参数化策略无法充分拟合目标。

这与 RAE 的实际训练过程直接对应。

但我建议将它作为第三优先级。

因为前两个理论问题更直接体现 RAE 的算法新颖性，而第三个结果可能主要是标准蒸馏误差分析。

除了理论问题，我认为还有几项实现细节需要在 P0 阶段处理。

优先级	问题	为什么重要	建议

\rightarrow

\rightarrow
\text{Controlled Probes}
\rightarrow
\text{Posterior Evidence}
\rightarrow
\text{Target Distribution}
\rightarrow
\text{Sequence-level Distillation}
}

然后逐步增加复杂机制。

十六、重新设计实验：一套更有说服力的 ICML 实验协议

我建议将现有 P0–P3 和 B1–B8 重新组织成三个实验层级。

实验层级 A：验证证据是否有效

目标：回答 RAE 是否能够比普通失败惩罚更准确地区分候选动作。

固定候选集合与探针数据，比较：

* 普通失败负优势；
* 经验成功率排序；
* Beta-Binomial 后验排序；
* 完整证据分数；
* oracle 动作价值。

主要指标：

* 最佳动作识别率；
* False Elimination Rate；
* 动作价值排序相关性；
* 目标分布误差。

这一层不需要先证明完整 Agent 成功率提高。

只要证据质量没有改善，就应该重新审视 RAE 的核心机制。

实验层级 B：验证预算分配是否有效

目标：回答 RAE 是否能在固定预算下获得更高的决策质量。

比较：

1. 均匀分配；
2. 熵驱动分配；
3. 当前双熵乘积；
4. 决策风险驱动分配；
5. 充分预算下的近似 oracle。

需要报告完整的预算—效果曲线。

此外，建议区分两种预算：

* 探针预算；
* 总交互预算。

只比较探针预算并不够，因为不同方法可能需要不同数量的初始 rollout。

实验层级 C：验证证据到策略更新的效果

目标：回答即使证据质量相同，目标分布蒸馏是否优于其他证据利用方式。

使用相同的候选动作与探针数据，比较：

* 不使用额外证据；
* 直接失败惩罚；
* APPO 式前缀回灌；
* RAE 目标分布蒸馏；
* oracle 目标分布蒸馏。

主要指标：

* 任务成功率；
* 失败恢复率；
* 独立验证成功率；
* 目标拟合误差；
* 同预算下的性能提升。

这一层能够直接检验你的主要主张：

失败证据通过目标分布通道利用，是否比通过传统优势或奖励通道利用更有效？

十七、如果我是 AC，我最可能追问你的五个问题

以下是我认为正式投稿时最可能遇到的核心质疑。

Q1：为什么需要 RAE，而不是多采样几次再用 GRPO？

这是最直接的问题。

你的回答不能只是“RAE 利用了失败信息”。

你需要展示：

在相同的总交互预算下，RAE 能够以更低的动作决策错误率，或者更高的失败恢复率，获得更好的结果。

同时，需要通过相同探针数据、不同训练通道的对照，证明收益来自证据利用方式，而不是额外样本。

Q2：为什么目标分布重构是必要的？为什么不能直接用动作级 reward？

这需要通过理论与实验共同回答。

理论上，你可以强调目标分布显式控制有限候选集上的相对概率质量。

但这本身还不够。

你需要证明或实证展示：相比直接使用动作级 reward，目标分布重构能够更稳定地保留有价值动作，同时削弱有充分负面证据的动作。

Q3：为什么你的预算分配优于均匀分配？

这是当前方案尚未解决的问题。

双熵乘积是合理的启发式，但不是天然具有最优性保证的算法。

如果没有额外理论，审稿人完全可能认为它只是一个经验性的采样规则。

这也是我最推荐优先发展的理论方向。

Q4：如果探针执行协议与真实 Agent 执行过程不同，证据还有什么意义？

这需要明确：

p_i^\mu(h)

是协议条件化的成功率，而不是动作在所有未来执行条件下的普适价值。

你的论文必须报告探针协议、预算、后续策略和终止规则，并通过协议变化实验检验结论的稳健性。

Q5：定理 1’ 为什么构成 ICML 的理论贡献？

目前它主要提供标准 KL 正则化优化的闭式解。

因此，我建议明确将它定位为目标构造的优化基础，而将主要理论贡献放在：

* 有限预算下的动作决策错误；
* 自适应预算分配；
* 目标分布误差传播。

否则，即使算法效果很好，理论评分也可能受到限制。

十八、我建议的修改路线：按研究价值排序

如果你准备正式推进 ICML 2027，我建议按照以下顺序工作。

第一阶段：先确保算法正确

1. 明确反事实探针必须执行指定候选动作。
2. 明确 p_{\mathrm{ref}} 的定义与执行协议。
3. 修正序列级蒸馏损失的实现。
4. 明确候选动作、探针样本与蒸馏样本之间的对应关系。

这四项没有完成之前，不建议大规模跑实验。

第二阶段：先验证核心算法是否有效

先实现最小版本：

* 失败触发；
* 候选动作生成；
* 指定动作的反事实执行；
* Beta-Binomial 后验；
* 简单的连续证据分数；
* 目标分布重构；
* 序列级 KL 蒸馏。

暂时关闭：

* 复杂可靠性权重；
* FIPO；
* upstream dead-end 回传；
* 复杂的多阶段触发；
* 多种动作粒度的组合。

先验证证据是否有用，以及证据到目标分布的通道是否优于直接惩罚。

第三阶段：发展核心理论

优先研究：

有限预算下的决策风险最小化与自适应证据获取。

如果这个方向能够形成明确的理论结果，它将比进一步优化熵阈值或者调整可靠性权重更有价值。

第四阶段：增加机制消融与跨环境实验

在核心算法成立之后，再研究：

* 熵与矛盾触发；
* BS 预筛；
* 自适应预算；
* 软证据与硬删除；
* 不同动作粒度；
* 不同后续执行协议；
* 不同候选生成器。

这样可以显著提高论文的可解释性。

十九、最终建议：RAE 应该如何定位为 ICML 论文？

我不建议将最终论文定位成：

一种融合 ARPO、APPO、贝叶斯估计和 KL 蒸馏的 Agent RL 算法。

这样的定位会使论文看起来像多个已有组件的集成。

我更建议定位为：

一种面向失败恢复的有限预算反事实学习框架，通过在关键决策状态上执行受控动作探针，获得可比较的动作级证据，并利用决策风险驱动的预算分配和证据加权目标重构，提高 Agent 在固定交互预算下的恢复能力。

其中，理论贡献应该集中在两个方面：

1. 有限预算下的反事实证据获取与动作决策保证。
2. 证据不确定性如何影响目标分布，以及自适应预算何时优于均匀分配。

目标分布的闭式解、Beta-Binomial 后验和 KL 蒸馏则作为算法构件。

我的最终审稿意见

RAE 的方向值得继续推进，但当前最重要的不是增加更多模块，而是把三个关键问题真正解决：

第一，反事实探针是否真的评估了指定动作。

这是算法正确性的基础。

第二，有限预算下，为什么 RAE 能获得更好的决策证据。

这是论文最有潜力的理论贡献。

第三，为什么将这些证据转化为目标分布，比传统负优势或奖励调整更有效。

这是方法贡献与实验归因的核心。

如果这三个问题都能得到严格的定义、可靠的实现和充分的实验支持，那么 RAE 就有机会从一个合理的 Agent RL 工程方案，发展为一篇具有清晰算法贡献和理论深度的 ICML 论文。

反之，即使完整系统最终取得更高的成功率，如果无法排除额外采样预算、训练目标变化和探针执行差异等因素，审稿人仍可能认为论文的核心贡献不够明确。

我最建议你下一步集中研究的方向是：把 RAE 的自适应探针分配形式化为一个有限预算的决策风险最小化问题，并围绕它建立理论保证。 这比继续完善当前的熵启发式，更可能成为论文真正有辨识度的贡献。
