# DAPO — Decoupled Clip and Dynamic Sampling Policy Optimization

## 1. 出处
- Venue / arXiv / 日期：arXiv:2503.14476
- 角色：GRPO 族 Loss 稳定性代表

## 2. Abstract 要点（综合社区共识 / 既有核对）
- 修复 GRPO 训练动力学：clip-higher、动态采样过滤零方差组、token 级损失归一、超长惩罚等。
- 目标仍是可验证结局奖励上的组相对优化。
- 广泛被后续 agentic RL 当作默认稳定化器。

## 3. Intro 诊断的社区盲区
组相对优化在全对/全错或裁剪不当时常坍缩、不稳。

## 4. 方法三层定位
| 层 | 内容 |
| --- | --- |
| Rollout | 标准组采样；可滤零方差组 |
| Advantage | 组内标准化 outcome |
| Loss | 非对称 clip 等 |
| 失败用法 | 丢掉全错组 / 负优势——与 RAE“失败侧仍良定义”相反 |

## 5. 实验设定线索
- 多为数学/推理；在搜索设定中作为 **Loss 插件** 叠在 Search-R1 管线上即可。

## 7. 与 RAE：同 / 异 / 优 / 劣
- **相似**：RAE 的 $A^{\mathrm{RAE}}$ 可跑在 DAPO clip 上。
- **不同**：只修更新动力学，不改失败语义。
- **对方优势**：审稿人常问“是不是训练不稳”；必须有。
- **对方劣势**：丢掉全错组与 G3 直接冲突。
