# BranPO

## 1. 出处
- Venue / arXiv / 日期：arXiv:2602.03719
- 角色：对比分支 / 非单调正确性

## 2. Abstract 要点（基于既有核对）
- 截断前缀、重采样续写，构造同前缀不同结局的对比分支。
- 提出 non-monotonic correctness：早错可被后步救；看似好的中间态可因后续失败。
- 学对比优势/偏好，而非支持集投影。

## 3. Intro 诊断的社区盲区
中间步对错与最终结局非单调；需要同前缀不同结局才构成有效监督。

## 7. 与 RAE：同 / 异 / 优 / 劣
- **相似**：同前缀分叉、非单调正确性（贴近 C2 归因）。
- **不同**：对比优势 ≠ $\mathrm{Renorm}(\pi_{old}\setminus a_f)$；无成功侧时目标不立。
- **对方优势**：可打“你们只是对比学习”。
- **对方劣势**：失败侧单独不构成良定义目标。
